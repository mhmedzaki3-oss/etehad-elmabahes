# عمارة ش المباحث
تطبيق ويب (PWA) لإدارة اتحاد الشاغلين (22 شقة): يُثبَّت على الموبايل ويعمل بدون إنترنت بعد أول فتح.

## حساب العمارة
رصيد أول الشهر + المسدد من الشقق (+ إيرادات أخرى) − المصروفات العامة = رصيد آخر الشهر، ويُرحَّل رصيداً افتتاحياً للشهر التالي.

## الاستخدام
- **المدير:** يدخل بكلمة مرور ينشئها أول مرة، ويسجل الاشتراكات (لكل شقة اشتراكها) والمصروفات العامة والمتأخرات السابقة وأسماء الجيران.
- **الجيران:** المدير يضغط «🔗 رابط عرض للجيران» ويرسله في واتساب (قراءة فقط بدون حساب).
- **التنبيهات:** أي ساكن يرسل مشكلة عبر واتساب، والمدير يسجلها ويكتب الإجراء المتخذ، وتظهر للجميع أعلى الصفحة الرئيسية.
- **تغيير المدير كل 3 شهور:** القديم يرسل «نسخة احتياطية» والجديد يستعيدها، ثم يغيّر الاسم ويخفي/يغيّر ملف `manager.jpg`.

## تنبيهات
كلمة المرور تقفل الواجهة فقط والبيانات غير مشفرة على الجهاز. رابط العرض يحمل البيانات داخله فلا يُنشر خارج مجموعة العمارة. ليس اعتماداً محاسبياً أو قانونياً. صورة المدير في المستودع، فاحذف `manager.jpg` إن كان المستودع Public ولا تريد نشرها.
